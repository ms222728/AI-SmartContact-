# SmartContact

**AI-Powered Daily Action Tool for Real Estate Agents**

SmartContact helps real estate agents manage leads, prioritize follow-ups, and close more deals with intelligent daily task lists.

## 🚀 Live Site
[https://ms222728.github.io/AI-SmartContact-](https://ms222728.github.io/AI-SmartContact-)

## Features
- AI-driven task prioritization every morning
- One-click AI-drafted texts and emails
- Smart scheduling synced with your calendar
- Performance insights and daily briefings
